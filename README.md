# HIM — He Is Memory

> PROJECT HIM：Minecraft Java Edition 26.3／Paper 伺服器的心理恐怖插件。
> 世界裡有一個會觀察、記憶、跟蹤、干擾，必要時會獵殺你的存在。他不需要一直出現——沉默本身就是他的選擇。

- **只需伺服器插件**：玩家使用原版客戶端即可，不需要模組或資源包。
- **不依賴 ProtocolLib／PacketEvents／NMS**：完全使用 Paper 26.3 公開 API。
- 正式名稱 **HIM**（He Is Memory），呼應本插件的核心：跨登入、跨重啟的持久記憶。

## 需求與安裝

| 項目 | 需求 |
|---|---|
| 伺服器 | Paper **26.3**（開發與測試使用 build 205） |
| Java | **25** 以上（Paper 26.3 官方最低需求） |
| 客戶端 | 原版 Minecraft Java Edition 26.3 |
| 相依插件 | 無 |

1. 將 `HIM-1.4.0.jar` 放入伺服器的 `plugins/` 資料夾。
2. 啟動伺服器，會產生 `plugins/HIM/config.yml`。
3. 依需要調整設定後執行 `/him reload`（設定有錯時會列出**所有**錯誤並保留原設定，不會無聲失敗）。
4. 建議執行一次 `/him selftest`（可在主控台執行）確認伺服器端功能正常，詳見[驗證狀態](#驗證狀態請先讀)。

> `/him selftest` 會建立一個名為 `him_selftest` 的超平坦測試世界，所有測試只在那個世界進行，不會修改遊戲世界。

## 快速開始

```
/him status                 狀態、效能、進行中的事件
/him summon <玩家>          讓 HIM 出現在玩家附近（確認外觀與私人可見性）
/him trigger <事件> <玩家>   立即觸發任一事件（測試用，不會影響記憶與性格）
/him chase <玩家> now        立刻開始一場追殺
/him debug <玩家>           看導演怎麼看待這位玩家：階段、張力、本次行動機率、可用事件
/him stop                   結束一切並移除所有 HIM
```

新玩家一開始處於「未察覺」階段：只會有難以確定的聲音。隨著實際遊玩時間與遭遇累積，HIM 才會現身、跟蹤、干擾，最後才可能追殺（預設約 2 小時遊玩且有數次顯著遭遇後）。

## HIM 如何運作

### 本體：Paper Mannequin
HIM 是一個穿著 Mojang 簽名經典白眼皮膚的 `Mannequin` 實體。它**預設對所有人隱藏**，只透過 `Player#showEntity` 顯示給指定玩家——這就是私人幻覺的實現方式：不相干的玩家客戶端根本不知道這個實體存在。本體沒有重力、沒有 AI、不會被存檔（`persistent=false`），且帶有標記，任何殘留都會在區塊載入時被清除。

### 追殺時的移動
追殺時「HIM 實際所在的位置」是一個虛擬載體：
- 由插件內建的 **A\* 網格尋路**（適用玩家大小的身體：上一格台階、下落三格內、游泳、爬梯子／藤蔓／鷹架、穿過木門與柵欄門，避開岩漿／火／仙人掌等）規劃路徑；
- 以精確速度沿路徑移動，Mannequin 每 tick 跟隨。

這樣的設計不依賴生物 AI，所以**不受伺服器「實體啟動範圍」影響**（遠離玩家的生物幾乎不運算），也不會在世界中留下隱形生物。這是實機測試後才確定的設計，見 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

### 恐怖導演（Horror Director）
沒有時間表。每位玩家每隔幾秒評估一次：
1. **危險率**：安靜越久越可能發生（Weibull 分佈），受階段、性格、環境（夜晚、地下、雷雨）、伺服器效能影響。
2. **張力節奏**：事件會累積張力 → 達到高峰（每輪隨機門檻）→ 進入**刻意的長時間沉默**，再重新累積。強度最高的事件（例如追殺）自然出現在累積的尾聲。
3. **全伺服器預算**：權杖桶限制全服總量，人多時不會變成鬼屋。
4. **意圖（Utility AI）**：在 存在感／觀察／跟蹤／干擾／追殺 之間依性格、玩家性情與情境計分選擇。
5. **事件**：依情境適配度、對這位玩家的新鮮度（避免重複）、HIM 學到的偏好加權抽選。
6. **模式與破格**：私人／群體／共享；以及是否刻意打破玩家已熟悉的規律。

模擬 24 小時（最高階段）的結果：平均每小時約 4 個事件、14 種以上不同事件、追殺約每 4 小時一次，且每次高峰後有約 25–30 分鐘的沉默（見 `HorrorDirectorTest`）。

### 記憶與人格
- **每位玩家**：活動熱點（16×16 區塊，會衰減）、由睡覺／開箱子／建造推測的**基地位置**、行為摘要（地下比例、夜間戶外、獨處、建造與挖掘速率）、對目擊的反應（無視／注意／靠近／逃跑／攻擊 → 性情）、追殺紀錄與**慣用逃脫方式**、對規律的熟悉程度、同伴關係、最近 48 次遭遇。
- **世界**：HIM 的性格（好奇、耐心、攻擊性、模仿、孤立偏好、膽量、破格傾向），每個伺服器隨機產生、隨經驗緩慢演化並向基準回歸；特殊地點（逃脫、死亡、被攻擊、登出的地點）；對各事件的偏好。
- **反制**：常從水中逃走的玩家會遇到更會游泳的 HIM；常跑贏的會遇到稍快的 HIM；常躲起來的會被搜得更久；常反擊的需要打更多下。
- **預期與破格**：玩家看過多次「靠近就消失」之後，HIM 有機會這次不消失——轉身離開、走出掩體、在窗外後退到黑暗中、門自己打開。

### 追殺
- 開始方式：從視線外接近，或（破格／由跟蹤升級）直接現身靜止凝視約 2 秒後開始。
- 行為：預測玩家移動方向、短暫爆發衝刺、失去視線後搜尋最後位置與逃跑方向、**假撤退**（轉身消失，在看不見的情況下繞到前方再出現）、開木門並在之後關上、被擊中時硬直。
- **公平逃脫**：持續衝刺（預設 HIM 奔跑 5.0 格／秒，玩家衝刺約 5.6）拉開 40 格以上 3 秒、中斷視線讓搜尋失敗、躲進有光照的室內、**把他打倒**（或打到重傷讓他撤退）、撐過 100 秒時限。
- **不作弊**：絕不在玩家看得到時瞬移；卡住時最多 2 次「在玩家看不到的情況下」重新定位；仍卡住就放棄並消失。
- 傷害：預設 5（會被遊戲難度縮放：簡單 3.5、普通 5、困難 7.5）、冷卻 1.2 秒；`chase.lethal: false` 時最多讓玩家剩半顆心。

**裝備（`chase.equipment`）**
- `adaptive`（預設）：新玩家遇到的是赤手空拳的經典 HIM；越常逃脫、擊退或打倒他的玩家，遇到的他準備得越充分——1 石／鐵級 → 2 鐵級＋鐵胸甲 → 3 鑽石級＋全套鐵甲 → **4 獄髓級＋全套獄髓裝，帶附魔光澤**（只給一再擊敗他的玩家）。在地下時他會拿鎬。偶爾會「降一級」，讓裝備不完全可預測。
- 武器不只有劍：**劍、斧頭、長矛、重錘（鑽石級以上）**，以及第 2 級起可能攜帶的**弓**與**喝擲藥水**。依玩家的習慣挑選——常逃跑的玩家較常遇到弓與緩速藥水，常反擊的玩家較常遇到斧頭與重錘。
- 附魔光澤只是外觀（`enchantment_glint_override`），不是真的附魔；他死不了也不會掉落，玩家拿不到這些裝備。
- 武器會增加傷害（鐵劍 +1、鑽石劍 +1.5、獄髓劍 +2，上限 `max-damage-bonus` 預設 2）；他穿的每件盔甲讓他受到的傷害 -8%（最多算 3 件）——即使全套獄髓，反擊仍然是可行的逃法。

| 武器 | 特性 |
|---|---|
| 劍 | 標準 |
| 斧頭 | 傷害略高；**你舉盾時一擊打掉你的盾**（盾牌冷卻 5 秒） |
| 長矛 | 攻擊距離 +1；衝刺時突刺（傷害與擊退更高）；精良級會保持在長矛距離 |
| 重錘 | 從高處落下時重擊（最多 +6）；攻擊較慢；精良級會用**風彈跳起**落在你身上 |
| 弓 | 你逃跑、或站在他上不去的地方時，停下拉弓射擊（預測你的移動、計算拋物線）|
| 三叉戟 | 你在水中、船上或雨中時自動換上：擲出（傷害 6）、激流衝刺（精良級）、喚雷（獄髓級、雷雨中、每場一次）；他游泳時改用游泳姿勢 |
| 藥水 | 緩速（對衝刺逃跑的人）、虛弱（對剛打過他的人）、黑暗（在暗處）；每場最多 3 瓶 |

他的箭、三叉戟與藥水**只會影響被追殺的玩家**，其他玩家看不到、也碰不到；不能撿、不會留在世界裡。

**打倒他（`chase.combat`）**
- 他有生命值（預設 60＝30 顆心）。你造成的就是你實際打出的傷害——武器、附魔、爆擊、弓箭都算。被打中時有受傷動作與聲音，並短暫硬直（10 tick 內的連擊不重複計算）。
- 重傷（低於 30%）時每次被打中有機率撤退。生命歸零時他倒地、化為煙霧消失，並**有 5% 機率掉落他的頭**（白眼皮膚的玩家頭顱）。
- 被打倒不是結束：他記得是誰。之後他的裝備更好、性格更具攻擊性，倒下的地點會成為他回訪的地方。
- `killable: false` 可恢復舊規則（被擊中 `hits-to-repel` 次後撤退）。

**精良級（鑽石＝3、獄髓＝4，`chase.elite`）**——像熟練的 PvP 玩家，但仍然可以被打倒：
- 左右走位、打一下就退出攻擊範圍、看到你拉弓會閃開、長矛保持距離。
- 拿重錘時用**風彈**跳起，落在你身上重擊。
- 你一直逃跑時喝一瓶**速度藥水**（每場一次，加成 10%：奔跑 5.0 → 5.5，仍略低於玩家衝刺的 5.6，衝刺逃跑仍然可行）。
- **獄髓級**：被追殺的人會看到他的 **BOSS 血條**；生命低於一半時**召喚怪物**協同作戰（預設 3 隻殭屍／骷髏，只攻擊被追殺的玩家、不掉落物品與經驗，追殺結束時化為煙霧消失）。
- 可用 `chase.equipment.max-tier` 限制最高等級、`enchant-glint: false` 關閉光澤；也可設為 `none` 或 `fixed`（`fixed.enchant-glint` 可讓固定裝備發光）。

**防堵追殺漏洞**——每一種躲法都有對應，但都保留公平的解法：

| 玩家的躲法 | HIM 的反應 |
|---|---|
| 墊高（柱子）| 走到下方，敲掉你腳下的方塊；搆不到就像玩家一樣墊高自己爬上來 |
| 挖洞把自己埋起來／躲進 1×1 坑 | 6 格內他「聽得到」你，不需要看見；挖開擋路的方塊進去 |
| 用柵欄、牆把自己圍住 | 靠近卻沒有進展時改為圍困，破壞擋路的方塊 |
| 梯子、藤蔓、鷹架 | 他會爬 |
| **鞘翅飛走** | 他不會飛：隱身並持續掌握你的位置，你一落地他已經在附近（你看不到的地方）。短暫滑翔不算；整場追殺累計在空中超過 30 秒（`chase.flight.escape-seconds`）才算真正逃脫，落地再起飛不會重置。飛行途中可能看到他站在前方地面上抬頭看你 |
| **指令傳送**（/tp、/home、/spawn、/tpa）| 幾秒後他出現在你傳送到的地方附近（包括其他世界），每場最多跟隨 2 次（`chase.teleport.follows`），再傳送一次才算逃脫。可選 `chase.teleport.block-commands: true` 讓被追殺的玩家完全無法用指令傳送 |
| 地獄門／終界門 | 視為正常遊戲中的逃脫，不跟隨 |
| **跳進水裡、坐船、站在雨中** | 他改拿**三叉戟**：擲出三叉戟、游得更快（仍略慢於玩家衝刺游泳）；精良級用**激流**衝過來；獄髓級在雷雨中**喚雷**一次；他的攻擊和三叉戟會打壞你坐的船。上岸後回到陸地打法 |
| **真正的室內**（有屋頂、有燈光）| **仍然安全**：他會在外面守一陣子，但不會破門而入——這是刻意保留的公平解法 |

圍困時的破壞與搭建：每場最多 12 個方塊（`chase.siege.max-blocks`）、只破壞硬度 ≤ 5 的方塊（黑曜石等不會）、**永不破壞箱子等方塊實體**、遵守 `mobGriefing`、先發出「實體改變方塊」事件讓 WorldGuard 等保護插件可以阻止，所有變化寫入回滾日誌並在無人時還原。

**經常用同一種方法逃脫的玩家，下次會遇到針對性的他**（例如經常飛走的玩家，空中時間會變長才算逃脫；經常游泳逃走的玩家會遇到更會游泳的他）。

### 告示牌對話

在告示牌上寫給他的話，他會讀，並在幾分鐘後回覆（`signs.*`）：
- 回覆會出現在**同一塊告示牌上**，在你回到附近、沒有看著它的時候。**只有寫字的人看得到**——朋友看到的仍是你原本寫的字。之後幾天內，你每次回來看到的都是他的回覆。
- 他會判斷你寫的是問候、挑釁、請求、還是問題（中文與英文），並用你寫的語言回答：
  - 「你是誰」→「我是你／忘記的／東西」、「我認識你／12 天了」……
  - 「你想要什麼」→ 你朋友的名字。
  - 「為什麼」→ 你上次看到他的座標。
  - 有時他不回答，只是把你的字抹掉。
- **改變態度**：挑釁會讓他更執著、很快再出現；請他離開，有時他會答應並給你一段平靜（20–60 分鐘），有時說「好」卻不遵守，求太多次他會回「你上次也這麼說」。
- 不是寫給他的告示牌（「倉庫」「礦坑入口」）偶爾也會被回應。
- 這一切都是只送給該玩家的假告示牌內容，**世界中的真實告示牌不會被修改**。

## 資料與記憶

```
plugins/HIM/data/
├── players/<UUID>.json     每位玩家的記憶（有上限，不保存逐 tick 資料）
├── world-state.json        HIM 的性格、特殊地點、事件偏好、建築區
└── world-changes.json      真實世界修改的回滾日誌
```

- JSON，寫入時先寫暫存檔再原子替換；損毀的檔案會被改名為 `.corrupt-<時間>` 隔離並重新開始，不會覆蓋。
- 讀寫都在獨立 IO 執行緒；序列化在伺服器執行緒完成，IO 執行緒不接觸可變物件。
- 自動存檔（預設 5 分鐘）、玩家離線時存檔、關服時同步等待寫入完成。
- `memory.forget-after-days`（預設 180 天）未上線的玩家資料會被刪除。

## 安全、效能與相容性

**世界安全**
- 假方塊只送給特定客戶端；固體假方塊不會放在玩家 3 格內，玩家靠近或互動時立即還原，事件結束／換世界／關服時全部還原。
- 真實修改只限天然方塊（天然樹葉以「非持久」屬性判斷，玩家放的樹葉不會被動），遠離世界出生點、玩家床位、HIM 推測的基地與玩家大量建造的區塊（預設 48 格），遵守 `mobGriefing`，**先寫入日誌再修改**；到期後只在 40 格內沒有玩家時還原，且只在方塊仍是 HIM 放的狀態時還原（玩家改過就尊重玩家）；關服時立即還原所有已載入區塊中的修改，其餘重啟後繼續處理。
- 唯一會留下的變化是 `door_left_open` 打開的門（只開門，不破壞）；可用 `world-modification.door-interaction: false` 關閉。

**多人協調**
- 每位玩家同時最多參與一個事件（鎖定），群體事件鎖定所有參與者。
- 全服身影上限（預設 3）、追殺上限（預設 1）、全服恐怖預算。
- 玩家離線、死亡、換世界、長距離傳送時，相關事件立即結束並清理（追殺例外：指令傳送會被跟隨，見「追殺」）；離線發生在遭遇中會被記住，回來時……他在等。

**效能**
- 所有世界存取都在伺服器主執行緒，且**絕不載入區塊**（視線、尋路、找位置遇到未載入區塊一律視為牆）。
- 玩家情境取樣錯開在不同 tick；視線檢查隔 tick 執行；尋路有節點上限（3000）並只在目標明顯移動時重新規劃。
- 效能守衛：伺服器 MSPT ≥ 40 或 HIM 自身超過每 tick 預算時降低頻率並暫停新追殺；MSPT ≥ 48 或 TPS < 17 時結束所有事件，直到恢復（啟動後 90 秒內不採用 TPS 平均值）。
- 實測（本機 Paper 26.3）：HIM 閒置約 0.03 ms/tick；導演一次決策約 1–5 µs。

**相容性**
- 會被其他插件取消的生成（例如區域保護禁止生物生成）會被安全地視為「此處無法發生」。
- 其他生物不會以 HIM 為目標；HIM 的實體不受傷害、不燃燒、不轉化。
- 世界保護插件：追殺時的圍困破壞／搭建會先發出 `EntityChangeBlockEvent`，WorldGuard 等插件可以阻止；事件類的真實修改（無葉樹、通道）則不會詢問區域權限（沒有通用 API）。若伺服器重度依賴區域保護，建議設定 `world-modification.real-changes: false`，或以 `worlds` 黑名單排除。
- `folia-supported: false`：未支援 Folia。

## 驗證狀態（請先讀）

本專案區分四種狀態。**「編譯成功」不等於「恐怖效果在玩家眼中完全正常」。**

| 狀態 | 意義 |
|---|---|
| ✅ 自動化測試 | JUnit 單元測試（71 項，`./gradlew test`）通過 |
| ✅ 伺服器實測 | 在真實 Paper 26.3（build 205）上以 `/him selftest`（32 項）通過 |
| ✅ 協定層實測 | 以無頭測試客戶端（mineflayer，26.1 協定經 ViaBackwards 轉譯）連入真實 Paper 26.3，記錄客戶端**實際收到的封包**驗證 |
| ⏳ 尚待驗證 | 需要真人使用原版 26.3 客戶端觀察的項目 |

**已在真實伺服器與測試客戶端上驗證：**
- 私人可見性：目標客戶端收到 Mannequin，旁邊 4 格內的另一位玩家**完全沒有收到**該實體；共享模式兩人都收到；`/him stop`、玩家離線後實體被移除，世界中無殘留。
- 群體事件的資訊不對稱：`behind_companion` 一人看到 HIM、另一人只收到一個腳步聲；`cave_mining` 群體模式兩人收到來自不同方向的挖掘聲。
- 私人聲音、假加入訊息、假告示牌（方塊與文字）、火把熄滅與還原、方塊裂痕動畫、神龕（31 個假方塊，走近時一次還原）只送給目標。
- 凝視判定使用真實客戶端的視角：遠方身影被盯住約 1 秒後消失；窗外身影在移開視線後消失；探頭者被發現後退回掩體再消失；背後身影在轉身後一瞬消失。
- 追殺：現身、接近、攻擊（含冷卻）、持續逃跑可逃脫、擊中 6 次擊退、玩家中途離線立即清理、死亡依實際傷害來源歸因。

- 導演自然運作：在加速設定下自然觸發 `leafless_tree`、`dread`、`false_join` 等並正確記錄。

- 打壞船：測試客戶端無法持續坐在船上，這部分只完成程式與編譯，尚未實測。
- 戰鬥手感：拉弓與喝藥水的動畫、倒地姿勢、風彈跳躍的軌跡在原版客戶端上看起來是否自然；緩速藥水需要真人衝刺才會觸發（測試客戶端無法衝刺）；長矛距離與走位的實戰感受。
- 需要真實移動的反應判定（逃跑／靠近），以及需要睡覺、挖掘、真人走位的事件（`bed_watcher`、`mimic_echo`、`landmark_return`、`return_greeting`、`door_left_open`）的整體體驗。
- 長時間多人遊玩下的節奏感是否「克制且難以預測」（已用模擬驗證統計特性，體感仍需真人確認）。

完整清單與步驟見 [`TESTING.md`](TESTING.md)。

## 已知限制與問題

- **測試客戶端的限制**：自動化連線測試使用 26.1 協定的 mineflayer 經 ViaBackwards 轉譯；測試客戶端關閉了物理運算，玩家「移動」以伺服器傳送模擬。這驗證了封包層面的正確性，但不等同原版客戶端的畫面。
- **傷害受難度縮放**：追殺傷害使用 `MOB_ATTACK` 傷害類型，會依難度縮放；和平難度下傷害為 0（追殺仍會發生，但不會造成傷害）。
- **世界保護插件**：見上方相容性說明。
- **他召喚的怪物是真實的**：私人追殺時，旁邊的其他玩家也看得到這些怪物（HIM 本身與他的箭、藥水仍只有被追殺的人看得到）。不想要可設 `chase.elite.minions.enabled: false`。
- 他的箭不會因為其他保護插件的 PvP 設定而失效（它們由 HIM 發出，不是玩家）；若伺服器有特殊需求可關閉 `chase.weapons.bow`。
- **木門以外的門**：追殺尋路不會穿過鐵門與活板門。
- **開闊地形**：完全沒有遮蔽物的地形中，「需要掩體」的事件（探頭、追殺中的隱藏重新定位）會自動不發生或改用其他方式；這是刻意的。
- **Folia 不支援。**

## 發佈新版本

GitHub Actions（`.github/workflows/build.yml`）在每次推送與 PR 時以 JDK 25 建置並執行全部測試。
發佈新版本只需要：

1. 修改 `build.gradle.kts` 的 `version`（例如 `1.1.0`）。
2. 新增 `docs/releases/v1.1.0.md` 作為版本說明（沒有的話會自動產生）。
3. 推送到 `main`。CI 發現這個版本還沒有 Release 時，會建立 `v1.1.0` 標籤與 Release，並附上建置出的 JAR。
