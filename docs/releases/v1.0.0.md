# HIM — He Is Memory v1.0.0

Paper **26.3** 心理恐怖插件的第一個版本。玩家使用原版客戶端即可，不需要模組或資源包，也不依賴 ProtocolLib／PacketEvents。

## 需求
- Paper 26.3（測試於 build 205）
- Java 25

## 安裝
1. 下載下方的 `HIM-1.0.0.jar`，放入 `plugins/`。
2. 啟動伺服器，依需要調整 `plugins/HIM/config.yml`（全繁中註解），再執行 `/him reload`。
3. 建議在主控台執行一次 `/him selftest`，應顯示「32 項通過，0 項失敗」。

## 內容
- 以 Paper `Mannequin` 呈現的 HIM，搭配 Mojang 簽名的經典白眼皮膚；可個別只讓特定玩家看到。
- 恐怖導演：沒有時間表，依照張力節奏、性格、情境與伺服器效能決定何時、對誰、做什麼。
- 24 個自動事件加 1 個管理員召喚，支援私人、群體、共享三種模式。
- 追殺：A* 尋路、預測、爆發衝刺、假撤退、開木門；有明確公平的逃脫方式。
- 持久記憶：活動熱點、基地推測、行為與反應、慣用逃脫方式的反制、會演化的性格。
- 安全：假方塊只送給客戶端；真實修改只動天然方塊，先寫入回滾日誌，並在無人時自動還原。
- 效能守衛、`/him` 管理指令與權限、伺服器內自我測試。

## 驗證狀態
- 49 項單元測試通過；`/him selftest` 在真實 Paper 26.3 上 32 項通過。
- 協定層實測：以無頭測試客戶端（26.1 協定，經 ViaBackwards 轉譯）連入真實伺服器，驗證私人可見性、群體資訊不對稱、假方塊、追殺、世界修改還原與記憶持久化。
- **尚待原版 26.3 客戶端實機確認**：皮膚實際外觀、名牌是否隱藏、動畫與音效的聽感。詳見 README 的「驗證狀態」與 TESTING.md。

## 已知限制
- 追殺傷害會依遊戲難度縮放，和平難度下不會造成傷害。
- 真實世界修改不會查詢 WorldGuard 等區域保護插件，需要時請關閉 `world-modification.real-changes`。
- 不支援 Folia。
