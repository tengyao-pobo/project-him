# HIM — He Is Memory v1.1.0

追殺不再有捷徑，HIM 學會冒充你的朋友，也開始回覆你寫給他的告示牌。

## 安裝／升級
1. 以 `HIM-1.1.0.jar` 取代舊的 JAR，重新啟動伺服器。
2. 舊的 `config.yml` 不需要修改：新設定項目未出現時一律使用預設值。想調整時，可參考 JAR 內的新 `config.yml`（`chase.siege`、`chase.equipment`、`chase.flight`、`chase.teleport`、`impersonation`、`signs`）。
3. 玩家記憶自動沿用，不需轉換。

## 新功能

### 防堵追殺漏洞
| 玩家的躲法 | HIM 的反應 |
|---|---|
| 墊高（柱子）| 敲掉你腳下的方塊，或墊高自己爬上來 |
| 挖坑／把自己埋起來 | 近距離時聽得到你，挖開擋路的方塊 |
| 柵欄、牆圍住自己 | 沒有進展時改為圍困、破壞擋路的方塊 |
| 梯子、藤蔓、鷹架 | 他會爬 |
| 鞘翅飛走 | 隱身追蹤，你一落地他已經在附近；累計飛行 30 秒才算逃脫 |
| 指令傳送（/tp、/home、/spawn、/tpa）| 幾秒後跟到你身邊（含跨世界），每場最多 2 次；可選擇完全禁止 |
| 真正的室內（有屋頂、有燈光）| **仍然安全**——刻意保留的公平解法 |

所有破壞與搭建都有上限（每場 12 格）、只動硬度 ≤ 5 的方塊、永不破壞箱子等方塊實體、遵守 `mobGriefing`、可被 WorldGuard 等保護插件阻止，並寫入回滾日誌、在無人時自動還原。

### 追殺裝備
預設 `adaptive`：新玩家遇到赤手空拳的經典 HIM；越常逃脫或擊退他，他就準備得越充分（最高鑽石劍＋全套鐵甲）。地下拿鎬。武器增加傷害、盔甲增加擊退所需次數。

### 偽裝成你的朋友（`false_friend`）
你看到最常一起玩的朋友站在遠處看著你，或走開、停下、回頭等你跟上——真正的朋友在很遠的地方或另一個世界。只有你看得到。破格時偽裝剝落。`him.no-impersonate` 權限可讓特定玩家不被冒充。

### 告示牌對話
在告示牌上寫給他的話，幾分鐘後他會在同一塊告示牌上回覆，只有寫字的人看得到。他可能回答（用他記得的事）、抹掉你的字、或因此改變態度：挑釁會讓他更執著；請他離開，可能換來一段平靜，也可能只是一句他不打算遵守的「好」。支援中文與英文。

## 修正
- 玩家躲進 1×1 坑時，HIM 會因為「看不到」而放棄追殺（現在近距離能感知）。
- HIM 被一格牆或柵欄擋住時可能一直站著不動（現在會改為圍困）。
- 玩家長距離傳送時追殺被直接中止且不計入紀錄。
- 從「現身開始」的追殺在找不到可見位置時（例如玩家在坑裡）無法開始。

## 驗證狀態
- 65 項單元測試通過；`/him selftest` 32 項通過（Paper 26.3 build 205）。
- 所有新功能均以無頭測試客戶端連入真實 Paper 26.3 伺服器實測（詳見 README「驗證狀態」）。鞘翅以測試用輔助插件在伺服器端設定滑翔狀態模擬。
- **尚待原版客戶端與真人確認**：朋友皮膚的實際顯示（測試伺服器為離線模式）、真實鞘翅飛行的體驗、告示牌文字被替換的視覺感受。
