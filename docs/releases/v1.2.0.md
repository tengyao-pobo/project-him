# HIM — He Is Memory v1.2.0

## 新功能：適應式裝備第 4 級
一再擊退或逃脫他的玩家（約擊退 7 次，或等量的逃脫），會遇到準備最充分的 HIM：**獄髓劍＋全套獄髓裝，帶附魔光澤**。

- 附魔光澤只是外觀，不是真的附魔；他不會死也不會掉落，玩家拿不到這些裝備。
- 為了保留「反擊」這條逃脫路線，裝備的效果有上限：武器傷害加成最多 +2（`chase.equipment.max-damage-bonus`），盔甲讓擊退所需次數最多 +3（`max-repel-bonus`）。
- 和其他等級一樣偶爾會「降一級」，不完全可預測。

## 新設定（`chase.equipment`，舊設定檔不需修改，未設定時使用預設值）
| 設定 | 預設 | 說明 |
|---|---|---|
| `max-tier` | 4 | adaptive 最高等級（0-4）；不想要獄髓就設 3 |
| `enchant-glint` | true | 第 4 級帶附魔光澤 |
| `fixed.enchant-glint` | false | fixed 模式的裝備是否發光 |
| `max-damage-bonus` | 2.0 | 武器傷害加成上限 |
| `max-repel-bonus` | 3 | 盔甲增加擊退次數上限 |

## 驗證狀態
- 66 項單元測試通過；`/him selftest` 32 項通過（Paper 26.3 build 205）。
- 實測：測試客戶端收到的每件獄髓裝備都帶 `enchantment_glint_override`；攻擊傷害為 7（基礎 5＋上限 2）。
- 尚待原版客戶端確認光澤的實際觀感。
