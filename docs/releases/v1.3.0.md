# HIM — He Is Memory v1.3.0

他可以被打倒了。他也學會了更多武器，而且越強的他越像一個真正的高手。

## 打倒他
- 他有生命值（預設 60＝30 顆心），你的武器、附魔、爆擊、弓箭都算數。被打中時有受傷動作、聲音與硬直。
- 重傷時可能撤退；生命歸零時倒地化為煙霧，**有 5% 機率掉落他的頭**（白眼皮膚的玩家頭顱）。
- 他記得是誰打倒他：之後的他裝備更好、更具攻擊性。
- `chase.combat.killable: false` 可恢復舊的「擊中 N 次後撤退」規則。

## 武器
| 武器 | 特性 |
|---|---|
| 劍 | 標準 |
| 斧頭 | 打掉你舉起的盾 |
| 長矛 | 攻擊距離 +1，衝刺時突刺 |
| 重錘 | 從高處落下重擊（鑽石級以上）|
| 弓 | 你逃跑或躲在高處時停下射擊 |
| 喝擲藥水 | 緩速、虛弱、黑暗 |

適應式裝備會依玩家習慣挑選：常逃跑的玩家較常遇到弓與緩速藥水，常反擊的玩家較常遇到斧頭與重錘。他的箭與藥水只影響被追殺的玩家。

## 精良級（鑽石／獄髓）
- 像熟練的 PvP 玩家：左右走位、打一下就退、看到你拉弓會閃、長矛保持距離——但仍然可以被打倒。
- 拿重錘時用**風彈跳起**落下重擊。
- 你一直逃跑時喝一瓶**速度藥水**（加成 10%，仍略低於玩家衝刺速度）。
- **獄髓級**：顯示 **BOSS 血條**；生命低於一半時**召喚怪物**協同作戰（只攻擊被追殺的玩家、不掉落、結束後消失）。

## 新設定
`chase.combat`、`chase.weapons`、`chase.elite`，以及 `chase.equipment.fixed.ranged`／`fixed.potions`。舊設定檔不需修改。

## 修正
- 舊版設定檔缺少清單類設定時（例如升級後），清單會被讀成空的而不是使用預設值。

## 驗證狀態
- 71 項單元測試通過；`/him selftest` 32 項通過（Paper 26.3 build 205）。
- 以測試客戶端在真實伺服器上實測：打倒、BOSS 條、頭顱掉落、召喚與清除、風彈跳躍重擊、弓箭（只有目標收到）、虛弱藥水、速度藥水。
- **尚待原版客戶端與真人確認**：拉弓／喝藥水／倒地的動畫觀感、風彈跳躍軌跡、緩速藥水（需要真人衝刺）、長矛距離與走位的實戰感受。
