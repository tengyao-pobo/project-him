# HIM — He Is Memory v1.4.0

跳進海裡不再是穩贏的逃法。

## 三叉戟與水中追擊（`chase.water`）
你在水中、坐船或站在雨中時，他改拿三叉戟：
- **擲出三叉戟**（傷害 6，冷卻 2.5 秒）。只有被追殺的玩家看得到、碰得到，撿不起來、不會留在世界裡。
- **游得更快**：奔跑速度 × 0.9（4.5 格／秒），仍略慢於玩家衝刺游泳——海還是一條逃生路，只是不再穩贏。他游泳時改用游泳姿勢。
- **激流**（精良級）：在水中或雨中直線衝向你，命中時傷害更高。
- **喚雷**（獄髓級、雷雨中、每場一次）：閃電落在你身上。
- **打壞船**：他的攻擊與三叉戟會打壞你坐的船，船掉落成物品，你落水。
- 上岸後他收起三叉戟，換回原本的武器。

所有項目都能在 `chase.water` 調整或關閉。舊設定檔不需修改。

## 修正
- 拿出三叉戟時，傷害與攻擊距離不再沿用原本武器（例如長矛）的加成。

## 驗證狀態
- 71 項單元測試通過；`/him selftest` 32 項通過（Paper 26.3 build 205）。
- 以測試客戶端在真實伺服器上實測：換上三叉戟、擲出（只有目標收到）、激流命中、游泳姿勢、雷雨中喚雷。
- 實測時發現並修正兩個問題：浮在水面的玩家不被視為「在雨中」；喚雷的傷害來源設定錯誤導致例外。
- **尚未實測**：打壞船（測試客戶端無法持續坐在船上）。**尚待原版客戶端確認**：游泳與激流的動作觀感。
