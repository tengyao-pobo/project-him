# HIM — He Is Memory v1.4.1

## 改進
- **圍困時拿對應的工具**：破壞方塊時，他會拿出適合的工具——石頭類用鎬、木頭用斧、泥土沙子用鏟、樹葉羊毛用剪刀；材質跟著他的裝備等級（石→鐵→鑽石→獄髓）。墊高時手上拿著要放的方塊，做完換回原本的武器。

## 修正
- 鑽石級以上的他（會走位的精良級）在玩家墊高時，會因為走位而誤判「搆得到」，結果永遠不會圍困。現在走位只在玩家與他同一高度時使用。

## 驗證狀態
- 72 項單元測試通過；`/him selftest` 32 項通過（Paper 26.3 build 205）。
- 實測：玩家站在 4 格高的泥土柱上，客戶端依序收到他手上的長矛 → 獄髓鏟 → 地獄石 → 長矛，圍困正常進行。
