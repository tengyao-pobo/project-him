# HIM — He Is Memory v1.4.2

## 修正
- **弓箭、三叉戟等投擲物打不到他**：追殺時的本體被設為「不可碰撞」，在 Paper 中這也代表投擲物會直接穿過。現在追殺時投擲物可以正常命中並造成傷害（遠方顯現等非追殺事件中他仍然摸不到）。
- **打擊感像在打無敵／創造模式的玩家**：原本傷害事件被直接取消，原版客戶端因此播放「無效攻擊」的回饋。現在打中他就像打中一般生物：閃紅、爆擊與橫掃效果、打擊音效，並被擊退（衝刺或重擊退得更遠）。他的生命值仍由插件自己計算。
- 私人追殺時，看不到他的其他玩家射出的箭會直接穿過他，不會打中一個看不見的東西。

## 驗證狀態
- 72 項單元測試通過；`/him selftest` 32 項通過（Paper 26.3 build 205）。
- 實測：玩家射箭 4 發 4 中（每發 6 傷害）、三叉戟命中（8 傷害）；近戰時客戶端收到受傷封包；看不到他的另一位玩家射的箭全部穿過落地。
- **尚待原版客戶端確認**：實際的打擊手感（閃紅、擊退距離）。
