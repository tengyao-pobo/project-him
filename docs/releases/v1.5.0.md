# HIM — He Is Memory v1.5.0

## 新功能
- **藥水箭**：他射出的箭有 25% 機率是藥水箭（預設效果：中毒、緩速、虛弱、傷害）。可用 `chase.weapons.tipped-arrow-chance` 與 `tipped-effects` 調整，另可選凋零、失明、噁心、飢餓。`chase.lethal: false` 時不會使用傷害與凋零。藥水箭與一般的箭一樣，只會影響被追殺的玩家。
- **手動追殺可指定裝備等級**：
  - `/him chase <玩家> [now] [0-4]`
  - `/him trigger hunt <玩家> [now] tier=0-4`
  - 0 赤手空拳、1 石、2 鐵、3 鑽石、4 獄髓。該等級的武器仍會隨機挑選（例如第 4 級可能是獄髓劍、斧、長矛或重錘），但不會被「降一級」。不指定時依設定檔。

## 驗證狀態
- 73 項單元測試通過；`/him selftest` 32 項通過（Paper 26.3 build 205）。
- 實測：藥水箭（傷害、緩速、虛弱）射出，被追殺的玩家實際中了緩速與虛弱效果；指定等級 2、4、0 分別得到對應裝備，無效等級與對非追殺事件指定等級會顯示錯誤訊息。
