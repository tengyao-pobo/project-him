# HIM — He Is Memory v1.6.0

## 新功能：終界珍珠（精良級）
路走不到時——峽谷、懸崖、護城河、你站的高台——鑽石級以上的他會丟一顆終界珍珠到你附近。

- **看得到**：珍珠會飛過來、有聲音與粒子，你有機會反應。只有被追殺的玩家看得到。
- **只在走不到時用**：必須連續 1.5 秒走不到你、而且他確實被地形卡住；平地追逐時不會用，衝刺逃跑仍然有效。
- **不丟進真正的室內**（有屋頂、有燈光的房間仍然安全），最遠 30 格，每場 2 顆，有冷卻。
- **有代價**：落地時他和玩家一樣會受傷（5 點，從他的生命值扣，但不會因此死亡）。
- **取代部分作弊**：看得到你、手上還有珍珠時，他優先丟珍珠，而不是在你看不到時繞過去。
- **他會記得你愛用珍珠**：追殺中常丟珍珠逃跑的玩家，之後較常遇到帶弓的他。

設定在 `chase.elite.ender-pearl`。舊設定檔不需修改。

## 驗證狀態
- 74 項單元測試通過；`/him selftest` 32 項通過（Paper 26.3 build 205）。
- 實測：玩家在護城河包圍的島上，拿斧頭的他丟珍珠上島並攻擊，拿重錘的他改用風彈跳躍；平地追逐兩次沒有丟珍珠。
- 實測時發現並修正：快速移動的目標會讓路徑規劃短暫判定「走不到」，造成他在平地丟珍珠。
