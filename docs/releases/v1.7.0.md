# HIM — He Is Memory v1.7.0

## 生命值依裝備等級
他不再那麼容易倒下，而且越強的他越耐打：0 級 40、1 級 60、2 級 90、3 級 130、4 級 200（20＝玩家的 10 顆心）。設定在 `chase.combat.health-by-tier`（取代原本的單一 `health`）。

## 新戰術（`chase.tactics`）
| 戰術 | 從 | 說明 |
|---|---|---|
| 盾牌 | 鐵級 | 約一半機率帶盾；你瞄準他或連續打他時舉盾，正面攻擊與箭被擋下；斧頭能打掉他的盾 5 秒 |
| 跳劈暴擊 | 鑽石級 | 跳起後落下暴擊（×1.4） |
| 金蘋果 | 鑽石級 | 半血以下邊後退邊吃（每場一次），回復 25%；被打中會被打斷 |
| 蜘蛛網 | 鑽石級 | 你逃跑時丟在你前方（每場一次）；真實方塊，之後自動還原，遵守保護範圍 |
| 不死圖騰 | 獄髓級 | 第一次被打倒時帶著 30% 生命站起來（每場一次） |

每個戰術都能用 `<戰術>-min-tier` 調整開始的等級，設為 5 即關閉。

## 修正
- 近戰時他會走到與玩家完全重疊的位置；現在停在一臂之遙、面對面打。

## 驗證狀態
- 74 項單元測試通過；`/him selftest` 32 項通過（Paper 26.3 build 205）。
- 以測試客戶端在真實伺服器上實測：各等級生命值、盾牌擋下攻擊、金蘋果被打斷與完整吃完（回復 25%）、不死圖騰、蜘蛛網（出生點保護範圍內不放、範圍外放下並寫入回滾日誌）。
